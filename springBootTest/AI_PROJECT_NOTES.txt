4. 上次踩过的坑（已写进脚本自动规避，不要再花时间排查）
----------------------------------------------------------------
- 【必看】SERVER__PORT 环境变量覆盖 server.port：
    本机/沙箱预设了 SERVER__PORT=56187（沙箱自己的端口，已被占用），
    Spring Boot 会读它，导致后端起在 56187 而启动失败（Address already in use）。
    脚本已在启动前 set SERVER__PORT= 清空，并 --server.port=8081 钉死。
    若手动 java -jar 一定要先 unset SERVER__PORT，否则必炸。
- Maven wrapper（mvnw）在本机不可用：项目缺 .mvn/wrapper 配置，且
    ~/.m2/wrapper/dists 下缓存的 apache-maven-3.9.9 / 3.9.16 的 lib 不完整，
    直接调用会报 classworlds Launcher 找不到。脚本已改成自动找 IDEA 内置 Maven
    或 PATH 的 mvn，别再折腾 mvnw。
- 端口 5173 残留进程：上次会话的前端若没正常退出，5173 会被占用，
    Vite 会漂到 5174。脚本启动前会先按端口杀掉旧进程，保证落在 5173。
- 两个 @RestController 不能同名（都叫 UserController 会 Bean 名冲突）。
    现已改名：AuthController（/api/auth）和 UserProfileController（/api/user）。别改回同名。
- MyBatis-Plus 配了 table-prefix=t_，实体类用 User 即可，无需 @TableName。
- 验证码是一次性的（防重放），联调时每个用例要重新领一张。
- 前端用 hash 路由（createWebHashHistory），地址是
    http://localhost:5173/#/login，部署不用配服务器重写。
